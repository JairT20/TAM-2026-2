# Teoría de Aprendizaje de Máquinas (TAM)

Repositorio general de entregas, evaluaciones y actividades prácticas del curso de **Teoría de Aprendizaje de Máquinas (TAM)**.

---

## 📁 Estructura del Repositorio

- **[`clasificacion_mnist/`](clasificacion_mnist/README.md)**: Clasificación de dígitos manuscritos con Deep Learning y OpenCV. Contiene su propia explicación técnica, código fuente y enlace a la aplicación en Streamlit Cloud.
- **`parciales/`**: Entregables, análisis teóricos y visualizaciones de las evaluaciones.
- **`talleres/`**: Talleres y prácticas del curso.
